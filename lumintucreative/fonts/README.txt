========================================================
  FOLDER FONTS – Lumintu Linktree
========================================================

Letakkan file font kustom kamu di folder ini:

  NAMA UTAMA (H1):
  ─────────────────
  Resedia-Regular.woff2
  Resedia-Regular.woff

  TAGLINE:
  ─────────────────
  OliveraVisual-Regular.woff2
  OliveraVisual-Regular.woff

Format yang didukung: .woff2 (diutamakan) dan .woff

Jika file font belum ada, browser akan memakai fallback font
serif (Playfair Display / Cormorant Garamond dari Google Fonts).
Tampilan tetap bagus meski font kustom belum dipasang.

Cara convert font TTF/OTF ke WOFF2:
  - Online: https://cloudconvert.com/ttf-to-woff2
  - CLI   : `fonttools` atau `woff2_compress`
